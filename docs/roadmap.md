# Roadmap

## Phase 1 - Foundation & Architecture

Create the monorepo foundation, backend shell, frontend shell, ML boundaries, configuration, logging, exceptions, database session foundation, tests, Docker, DVC, docs, AGENTS.md, and CI.

## Phase 2 - Dataset & Deep Learning Data Pipeline

Add dataset acquisition instructions, DVC tracking, validation, preprocessing, and split management without committing medical datasets to Git.

## Phase 3 - CNN + Transfer Learning + Evaluation

Implement model architectures, training loops, transfer learning, evaluation metrics, experiment tracking, and model checkpoint handling.

## Phase 4 - Explainability + Inference Engine

Add inference orchestration and explainability methods such as Grad-CAM, while preserving separation between ML code and the API application.

## Phase 5 - FastAPI + PostgreSQL + Authentication/RBAC

Add application models, migrations, authentication, role-based access control, and clinical workflow APIs.

## Phase 6 - React Dashboard + Reports + Human Review

Build the dashboard, image upload flow, analysis history, reports, and human review workflows.

## Phase 7 - Productionization + MLOps + Testing + CI/CD + Monitoring

Harden the system with production deployment workflows, monitoring, observability, model monitoring, and broader automated test coverage.
